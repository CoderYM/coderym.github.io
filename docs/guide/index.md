# 知识库总览

16 个模块，按「基础篇 → 核心篇 → 生态篇 → 工程篇」组织。每篇文章结构相同：

**学习目标 → 概念讲解 → 可运行代码（Python / Go / Java）→ 常见坑 → 小测 → 延伸阅读**

::: tip 怎么读
- 零基础：从 [00 导读](/guide/00-intro/what-is-agent) 开始按顺序读
- 有开发经验：可以跳过 01，从 [02 大模型原理](/guide/02-llm-basics/transformer) 或 [05 Tool Calling](/guide/05-tool-calling/concept) 开始
- 不确定的话，先看 [学习路线](/roadmap/)
:::

::: info 关于代码语言
示例代码以 Python 为主，同时提供 Go 和 Java 版本。在任意代码块上切换语言后，全站代码块会同步切换并记住你的选择。
:::
