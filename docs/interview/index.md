# 面试题

这里整理了 AI Agent 开发、大模型应用开发岗位中经常被问到的问题。题目按主题分为三部分，每题都附有参考答案，点击展开即可查看。

| 分类 | 内容 | 适合 |
| --- | --- | --- |
| [基础概念题](/interview/basics) | 大模型原理、提示词、Tool Calling、Agent 循环、上下文与记忆、MCP | 所有岗位 |
| [RAG 题](/interview/rag) | 切分、Embedding、向量检索、混合检索与重排、评估与优化 | 知识库、搜索、企业助手方向 |
| [工程与系统设计题](/interview/engineering) | 评估、可观测性、安全、成本、部署，以及完整的系统设计题 | 中高级工程师、架构师 |

## 怎么用这些题

- **先自己答，再看参考答案。** 能用自己的话讲清楚，比背下答案有用得多。
- **答案是提纲，不是标准。** 面试官更看重你的思考过程和真实经验，参考答案里的要点可以作为检查清单。
- **结合项目来答。** 每个问题都尽量联系自己做过的东西，比如"我在做知识库项目时遇到过……"。如果还没有项目经验，可以从 [实战项目](/projects/) 中挑几个做完。
- **答不上来就回去读文章。** 每页末尾列出了对应的知识模块。

## 面试官通常在考察什么

```text
  概念理解            工程能力               系统思维
 ┌──────────┐      ┌──────────────┐      ┌────────────────┐
 │ 原理讲得清 │ ──▶ │ 知道坑在哪里   │ ──▶ │ 能做权衡与取舍   │
 │ 不混淆概念 │      │ 有排查和优化手段│      │ 考虑评估、安全、 │
 │           │      │              │      │ 成本和可运维性   │
 └──────────┘      └──────────────┘      └────────────────┘
   初级岗位重点        中级岗位重点            高级岗位重点
```

对于大多数岗位，最容易拉开差距的是两件事：**你如何评估 Agent 的效果**，以及 **你如何处理 Agent 的失败**。准备时建议重点阅读 [为什么评估是第一优先级](/guide/14-evaluation/why-evals) 和 [工具错误处理与重试](/guide/05-tool-calling/error-handling)。

术语不熟可以查 [术语表](/glossary)。
