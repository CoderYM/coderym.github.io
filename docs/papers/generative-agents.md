# Generative Agents

## 论文信息

- 标题：Generative Agents: Interactive Simulacra of Human Behavior
- 作者：Joon Sung Park、Joseph C. O'Brien、Carrie J. Cai、Meredith Ringel Morris、Percy Liang、Michael S. Bernstein（Stanford University、Google）
- 年份：2023（UIST 2023）
- 链接：[arXiv:2304.03442](https://arxiv.org/abs/2304.03442)

## 一句话总结

给每个 Agent 配上"记忆流 + 检索 + 反思 + 规划"的架构，25 个 Agent 生活在一个虚拟小镇里，能够记住经历、形成观点、制定日程，并自发产生信息传播、组织聚会这样的社会行为。

## 要解决的问题

大模型可以在单次对话中扮演一个角色，但要让一个角色在很长时间里保持一致、可信的行为，会遇到几个难题：

- 经历越来越多，不可能全部放进上下文。
- 只看最近发生的事，Agent 会忘记重要的过去，行为前后矛盾。
- 只记录原始事件，Agent 难以形成更高层的认识（比如"某人是我的好朋友"）。
- 缺乏长期计划，Agent 的行为会显得随意、短视。

作者希望构建一种架构，让 Agent 能基于长期积累的经验做出可信的行为。

## 核心方法

架构的核心是 **记忆流（Memory Stream）**：一个按时间记录 Agent 所有经历的列表，每条记忆是一段自然语言描述，带有时间戳。围绕记忆流有三个关键机制。

```text
             感知环境（"厨房里的炉子着火了"）
                        │
                        ▼
 ┌──────────────────────────────────────────────────────────────┐
 │                       记忆流 Memory Stream                    │
 │  [观察] 08:00 在吃早餐       [观察] 09:10 和 Maria 聊天          │
 │  [反思] Maria 对研究很投入   [计划] 下午 2 点去图书馆              │
 └──────────────────────────────────────────────────────────────┘
        │ 检索                  ▲ 写入反思              ▲ 写入计划
        ▼                       │                       │
 ┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
 │ 检索 Retrieval    │   │ 反思 Reflection   │   │ 规划 Planning     │
 │ 得分 = 时近性      │   │ 重要性累计到阈值   │   │ 先粗后细地制定     │
 │      + 重要性      │   │ 时，总结出更高层   │   │ 一天的日程，遇到   │
 │      + 相关性      │   │ 的认识            │   │ 新情况时调整       │
 └──────────────────┘   └──────────────────┘   └──────────────────┘
        │
        ▼
   检索到的记忆 + 当前情境 ──▶ 大模型 ──▶ 行动 / 对话
```

- **检索：** 每条记忆有三个分数。时近性（越新越高，随时间衰减）、重要性（写入时由模型打分，"吃早餐"低，"分手"高）、相关性（与当前情境的 Embedding 相似度）。三者加权求和，取最高的若干条放进上下文。
- **反思：** 当近期记忆的重要性累计超过阈值时，Agent 会针对近期经历提出几个高层问题，检索相关记忆并总结出结论，这些反思本身也写回记忆流，可以被继续反思，形成层次。
- **规划：** Agent 先生成一天的粗略计划，再递归分解成更细的行动。计划同样存入记忆流，遇到意外事件时 Agent 会判断是否需要调整。

## 关键实验结论

- **涌现的社会行为：** 研究者只给一个 Agent 设定了"想办一场情人节派对"的初始意图，其他 Agent 在之后的模拟中自发传播邀请、互相约定、并在约定时间出现在派对现场。
- **消融评估：** 研究者通过"采访" Agent 来评估其行为可信度（询问它的计划、记忆、对他人的看法等），由人类评估者打分。完整架构的可信度最高；去掉反思、规划或记忆中的任何一项，可信度都会下降。
- **常见错误：** 检索不到相关记忆、在记忆基础上编造细节、以及受模型本身风格影响而过于礼貌、合作。

## 对 Agent 开发的启发

- **记忆需要分层。** 原始事件、提炼后的认识、计划，本质上是不同粒度的信息。这一思路直接影响了后来 Agent 记忆系统的设计，详见 [记忆的分类](/guide/08-memory/memory-types)。
- **检索不只看相关性。** "时近性 + 重要性 + 相关性"的组合打分非常实用。只用向量相似度做记忆检索，往往会漏掉重要但措辞不同的信息，或者召回过时的信息。
- **写入时就做加工。** 在写入记忆时让模型打一个重要性分数，或者定期把零碎记忆总结成高层结论，比读取时再处理更高效。
- **反思是"压缩"的一种形式。** 把大量细节总结成少量结论，既节省上下文，又提升决策质量，与 [压缩与摘要](/guide/07-context-engineering/compression) 的思路一致。

## 局限性

- 成本很高：每个 Agent 每个时间步都要多次调用模型，大规模、长时间模拟代价昂贵。
- 评估以"可信度"为主，属于主观指标，不能直接说明 Agent 在任务完成类场景中的效果。
- 记忆会不断增长，检索和反思的质量会受到影响，论文没有充分讨论遗忘和记忆冲突。
- Agent 的行为受底层模型的价值观和风格影响，表现得过于友善，与真实人类行为有差距。
- 研究场景是社会模拟，迁移到企业助手等任务型 Agent 时需要做较多取舍。
