# 学习路线

本站内容很多，不需要从头读到尾。先根据自己的背景选一条路径，再按路径里列出的文章和项目推进。每条路径都覆盖同样的 5 个阶段，区别在于每个阶段读多深、跳过什么、做哪个项目。

## 选择你的路径

| 你的背景 | 推荐路径 | 预计时长 | 重点 |
| --- | --- | --- | --- |
| 没写过代码，或只会一点脚本 | [零基础入门路径](/roadmap/beginner) | 约 16 周 | 先补编程和 HTTP 基础，再逐步进入 Agent |
| 有 1 年以上后端 / 前端 / 数据开发经验，没做过大模型应用 | [工程师路径](/roadmap/engineer) | 约 8 周 | 跳过编程基础，快速打通 Tool Calling、RAG、评估 |
| 做过大模型应用，负责技术选型或系统设计 | [架构师路径](/roadmap/architect) | 约 6 周 | 上下文工程、多 Agent、评估体系、安全与生产化 |
| 时间固定、希望有每周节奏 | [12 周学习计划](/roadmap/12-weeks) | 12 周 | 每周目标、必读、作业、自检问题 |

拿不准的话，用下面三个问题自测：

1. 你能不能用 Python（或 Go / Java）写一个调用 HTTP 接口并解析 JSON 的小程序？不能，选零基础路径。
2. 你能不能不看资料讲清楚 Tool Calling 中模型和你的代码各自做了什么？不能，选工程师路径。
3. 你能不能说出自己的 Agent 在上线前用什么评估集、什么指标衡量？不能，先走工程师路径的后半段，再看架构师路径。

## 5 个阶段

```text
 阶段1            阶段2              阶段3                 阶段4                    阶段5
 基础准备  ──▶  大模型与提示词  ──▶  Tool Calling  ──▶  上下文 / 记忆 / RAG  ──▶  多 Agent 与生产化
                                    与 Agent 循环          / MCP
 ─────────      ──────────────      ─────────────       ──────────────────       ─────────────────
 环境、Python    模型原理、API       让模型调用工具        让 Agent 拿到对的信息      让系统可评估、
 HTTP、异步      提示词、结构化输出   写出完整的 Agent 循环  接入外部生态              可观测、安全、可部署
```

| 阶段 | 核心问题 | 对应模块 | 代表项目 |
| --- | --- | --- | --- |
| 1 基础准备 | 我能写出调用 API 的程序吗 | 00 导读、01 编程基础 | [01 命令行聊天助手](/projects/01-cli-chat) |
| 2 大模型与提示词 | 我理解模型能做什么、怎么让它稳定输出吗 | 02 大模型原理、03 大模型 API、04 提示词工程 | [01 命令行聊天助手](/projects/01-cli-chat) |
| 3 Tool Calling 与 Agent 循环 | 我能让模型自己决定调用哪个工具、何时停止吗 | 05 Tool Calling、06 Agent 循环 | [02 天气日程工具 Agent](/projects/02-tool-agent)、[03 手写 ReAct Agent](/projects/03-react-agent) |
| 4 上下文 / 记忆 / RAG / MCP | 我能让 Agent 在长任务里拿到正确的信息吗 | 07 上下文工程、08 记忆系统、09 RAG、10 MCP、11 框架 | [04 个人 PDF 知识库](/projects/04-pdf-rag)、[05 MCP Server](/projects/05-mcp-server)、[06 网页研究员](/projects/06-research-agent) |

## 学习建议

- **每个阶段至少做一个项目。** 只读文章很难发现自己没懂的地方，代码跑不通时才会暴露问题。
- **自检清单过不了就别往下走。** 每条路径在阶段末都有自检清单，答不上来的条目回到对应文章重读。
- **评估越早接触越好。** 即便是零基础路径，也建议在阶段 3 就读一遍 [为什么评估是第一优先级](/guide/14-evaluation/why-evals)。
- **论文作为补充。** 完成阶段 3 后可以读 [ReAct](/papers/react)，完成阶段 4 后读 [RAG 原始论文](/papers/rag)。完整列表见 [论文精读](/papers/)。

如果你还不确定 Agent 是什么，先读 [Agent 到底是什么](/guide/00-intro/what-is-agent) 和 [如何使用本站学习](/guide/00-intro/how-to-learn)。
