学习目标 → 概念讲解 → 可运行代码（Python / Go / Java）→ 常见坑 → 小测 → 延伸阅读

怎么读

  • 零基础：从 00 导读 开始按顺序读

示例代码以 Python 为主，同时提供 Go 和 Java 版本。在任意代码块上切换语言后，全站代码块会同步切换并记住你的选择。
